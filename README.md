# 🥑 ПРОЕКТ: Telegram-to-Sheets NutriStat Automation Engine & Analytics Dashboard

Асинхронный сервис (Telegram-бот) для мгновенного логирования, ETL-трансформации неструктурированных данных о питании и автоматизированного биометрического анализа в реальном времени.

Система полностью заменяет коммерческие проприетарные трекеры (MyFitnessPal, Yazio), обеспечивая 100% независимость, кастомную аналитику трендов веса и нулевые задержки при вводе данных. Время рутинного ввода сокращено с 15 минут до 5 секунд в день через сквозной инжект данных.

---

## 🏗️ Архитектура и Компоненты Системы

Проект реализован в рамках паттерна MVC с упором на минимизацию накладных расходов и транзакций к API:

* **Telegram Injector (Входной слой):** Python-бот на базе `telebot` / `aiogram`. Принимает неструктурированный ввод (текст/логика составных блюд), валидирует его и пересылает в буферную зону БД.
* **Model / Warehouse (Google Sheets API):** Реляционно-связанное облачное хранилище. Разделено на листы сырых логов, справочники продуктов, базу комплексных рецептов ("Блюда") и исторический трекер биометрии.
* **Data Processing & Analytics (Вычислительный слой):** Тяжелая внутренняя логика на стороне таблиц. Включает ArrayFormula, динамические маппинги и кастомный математический алгоритм расчета скользящего среднего для веса.
* **Cron Cleaner Worker (Оптимизатор):** Автоматизированный Python-скрипт, запускаемый в конце операционного дня для дедупликации данных, закрытия суточного стейта и очистки буферных диапазонов.
* **Model / Warehouse (Google Sheets API):** [📊 Демонстрационная Google-таблица питания](https://docs.google.com/spreadsheets/d/1WMTx5eOHmuqCHWxYiK0yFFAHlp3aigBkeaJdRAM8UxQ/edit?gid=0#gid=0) *(Доступ: Только просмотр. Чтобы протестировать интерактивные функции и формулы — нажмите Файл -> Создать копию)*. Реляционно-связанное облачное хранилище...

## ⚡ Ключевые Инженерные Фичи

1. **Парсинг составных сущностей ("Блюда"):** Бот умеет обрабатывать не просто единичные продукты, а сложные составные рецепты, автоматически раскладывая их на макронуclientы (БЖУ) на основе матрицы тех-карт.
2. **Алгоритм дедупликации в буфере (Диапазон L5:S35):** Исключает дублирование записей и овер-логирование при повторных запросах, автоматически схлопывая стейт данных до отправки в постоянное хранилище.
3. **Биометрическое сглаживание (Moving Average):** Интегрирован расчет 7-дневного скользящего среднего для веса. Это сглаживает ежедневные колебания флюидов (воды/отеков) и выводит чистый математический тренд изменения массы тела.
